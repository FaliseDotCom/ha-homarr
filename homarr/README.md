# Homarr

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

A sleek, modern dashboard for your home lab, running on your Home Assistant server.

[Homarr](https://homarr.dev/) brings all your services together on customisable boards:
links with status pings, and widgets for media servers, downloads, DNS blockers, calendars,
weather and Home Assistant entities. Everything is set up in the browser; no configuration
files needed.

- Works on its own with its bundled database; no other apps required.
- Generates and keeps the encryption key for your stored secrets.
- Keeps all data in Home Assistant backups.
- Supports OIDC and LDAP sign-in through extra environment variables.
- Opens from the app page, the Companion app, or a sidebar dashboard.

See the **Documentation** tab for installation and configuration.
